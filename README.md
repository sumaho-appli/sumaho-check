# わが家のスマホ・SNS 1分チェック

保護者向けのスマホ・SNS啓発アプリ（試作版）。「はい」「いいえ」で答えるだけで、家庭で取り組むことがわかります。

- 公開ページ：https://sumaho-appli.github.io/sumaho-check/
- 対象：小学校低学年／高学年／中学生の保護者
- 構成：「守る」（大人が必ずやること）／「備える」（家族で話し合っておくこと）／「準備」（まだ持っていない家庭）
- 参考：宗像市教育委員会「児童生徒の携帯電話等の利用に関する指針」

回答は結果画面の「回答を送る」から、無記名のGoogleフォームに送信されます。

アプリを更新したときは `sw.js` の `VERSION` の数字を上げてください。

## 公開版とβ版
- 公開版：https://sumaho-appli.github.io/sumaho-check/ （保護者が使う。回答を送信する）
- β版：https://sumaho-appli.github.io/sumaho-check/beta/ （市の担当者・モニター保護者向け。回答は送信しない）
- 改良はまず `beta/index.html` に入れて確認し、問題なければ同じファイルをルートの `index.html` にコピーして公開する（2つは同じファイルで、置き場所によって動きが変わる）。
- 公開版の末尾に `?demo` を付けると、公開版のまま回答を送信しないお試しモードになる。
